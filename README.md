# pooka
Basic integration libraries for [blogthing](https://github.com/haku/blogthing). These should ideally be:
- minimal
  - leave as much as possible to the implementor
- easy to use
  - provide a simple API for blogs and metadata json
- flexible
  - let the implementor decide where blog files come from, select between raw html and markdown, etc.
